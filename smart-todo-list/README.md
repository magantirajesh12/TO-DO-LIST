# Smart To-Do List

A beginner-friendly to-do list web application built with HTML, CSS, and JavaScript. This project is designed to help students and job seekers showcase practical frontend skills in resumes and placement interviews.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as complete or incomplete
- Prioritize tasks as Low, Medium, or High
- Set due dates for each task
- Search tasks by name
- Filter tasks by All, Pending, and Completed
- View task statistics
- Clear all tasks with confirmation
- Persist tasks using browser Local Storage
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage

## How to Run the Project

1. Open the project folder in VS Code.
2. Open `index.html` in a browser, or run a local server.
3. If you want to use a local server from the terminal:

```bash
cd smart-todo-list
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
